# Speed Display

A full-screen GPS speed display application built with React. Shows current speed in kilometers per hour in a large, easy-to-read format.

## Features

- Full-screen display
- Large, clear numbers
- Dark theme for better visibility
- Responsive design that works on any screen size

## Development

1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser

## Deployment

The app is deployed at [https://magnusnordin.github.io/speed](https://magnusnordin.github.io/speed)
